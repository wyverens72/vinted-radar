# Cloudflare Free: размещение Vinted Radar

Версия 2 адаптирована к Cloudflare Workers + D1 + Cron Triggers. Аккаунты GitHub и Cloudflare уже созданы; репозиторий `wyverens72/vinted-radar` по выбору владельца публичный. Секреты в него не загружаются.

## Что бесплатно

Workers Free обслуживает сайт и API. D1 хранит личные поиски и очередь уведомлений. Cron Triggers проверяет расписание, Telegram доставляет сообщения через webhook. Используется выданный адрес workers.dev — покупать домен не нужно. Платные планы не включаем. Бесплатные квоты ограничены; подробности в официальных справочниках из README.

## Размещение с Mac

Из папки проекта:

```bash
npm ci
npm test
npm run build
npm run cloud:login
```

В браузере самостоятельно разрешите официальному Wrangler работу с Workers и D1. Далее создайте новую базу, если её ещё нет:

```bash
npx wrangler d1 list
npx wrangler d1 create vinted-radar
```

Вставьте ID созданной базы в `wrangler.jsonc`. Никогда не удаляйте и не пересоздавайте уже заполненную базу для обычного обновления.

```bash
npm run cloud:db:remote
npm run cloud:deploy
```

Откройте показанный адрес. Чтобы включить вход владельца, задайте секрет:

```bash
npx wrangler secret put APP_PASSWORD
```

Введите длинный случайный пароль, минимум 24 символа. Секрет не должен быть в GitHub. Остальные настройки Telegram описаны в README. После публикации проверьте поиск, перезагрузку, работу расписания при закрытой вкладке и установку PWA.

## Обновления

```bash
npm ci
npm test
npm run cloud:deploy
```

Постоянная база D1 не заменяется при обычной публикации Worker. Локальная старая SQLite автоматически в D1 не переносится. Папка `server/` и платный Render-шаблон оставлены как отдельный старый вариант; для бесплатного размещения они не используются.
