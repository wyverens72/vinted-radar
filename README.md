# Vinted Radar

Веб-приложение для поиска вещей на Vinted.pl с персональной лентой и уведомлениями в Telegram. Пользователь сохраняет фильтры, а приложение проверяет каталог в фоне и присылает подходящие объявления с фотографией, ценой и ссылкой.

[Открыть приложение](https://app.vinted-radar.workers.dev/) · [Telegram-бот](https://t.me/SNvintedradarbot)

## Возможности

- **Персональные поиски.** Настройка вручную или импорт фильтров по ссылке Vinted.
- **Фильтры каталога.** Категории с пошаговой навигацией, бренды, размеры, состояние, цвет и диапазон цен. В одной группе можно выбрать несколько значений.
- **Порядок выдачи.** Самые новые или рекомендованные Vinted.
- **Лента и избранное.** Найденные объявления сохраняются в аккаунте; более ранние результаты доступны через загрузку истории.
- **Telegram-уведомления.** Первые результаты и последующие находки отправляются отдельными карточками. Повторные находки в рамках одного поиска не создают новые уведомления.
- **Вход через Telegram.** Отдельные аккаунты с личными поисками, избранным и уведомлениями. Вход доступен в браузере и Telegram Mini App.
- **PWA.** Адаптивный интерфейс и установка приложения в поддерживаемых браузерах.

Текущая конфигурация рассчитана на небольшую группу: до 10 аккаунтов, включая владельца, и до 5 поисков на пользователя. Для регистрации можно использовать публичный вход через бота или одноразовые приглашения со сроком действия 24 часа.

## Как работает радар

1. Пользователь сохраняет поисковый запрос и фильтры.
2. Фоновый сборщик читает публичные страницы каталога и передаёт найденные объявления серверу.
3. Сервер сохраняет совпадения, исключает повторы и добавляет карточки в очередь уведомлений.
4. Результаты появляются в ленте; бот доставляет их в Telegram.

Каждая проверка начинается с первой страницы выдачи, затем продолжается просмотр более ранних результатов. Позиция просмотра сохраняется между запусками. Находки из начала выдачи получают приоритет при отправке.

Сборщик настроен на запуск примерно каждые 5 минут. Фактическая частота зависит от очереди поисков, доступности каталога и запуска GitHub Actions. Большие подборки отправляются постепенно. Открытая вкладка и постоянно включённый компьютер для мониторинга не нужны.

| --- | --- |

## Локальный запуск

Требуется Node.js 24 или новее.

```bash
npm ci
npm run build
npm run cloud:db:local
```

Создайте `.dev.vars` в корне проекта:

```dotenv
APP_PASSWORD=<случайный пароль длиной не менее 24 символов>
TELEGRAM_WEBHOOK_SECRET=<отдельный случайный секрет>
```

Для локальной проверки без внешних сервисов задайте демонстрационный источник:

```bash
npm run cloud:dev -- --var DATA_SOURCE:demo
```

Откройте [localhost:8787](http://localhost:8787) и войдите по паролю владельца. Локальная база отделена от облачной. После изменений интерфейса повторите `npm run build` и обновите страницу.

Для проверки настоящего входа и уведомлений нужен настроенный Telegram-бот и публичный HTTPS-адрес. Подробная инструкция — в [руководстве по развёртыванию](FREE_HOSTING.md).

## Данные и ограничения

Приложение работает с польским каталогом Vinted и ценами в PLN. Справочники фильтров сохранены как снимок публичного каталога от 24 октября 2026 года: 2 920 категорий, 5 901 бренд, 29 цветов и 5 состояний. Это не непрерывно обновляемая копия внутренней базы Vinted. Выбор размеров в интерфейсе проверен для женских джинсов, верхней одежды и обуви; для остальных категорий доступен импорт ссылки с фильтрами.

Публичные страницы читаются без входа в аккаунт Vinted. Пароли и cookies Vinted не запрашиваются. При отказе доступа сбор приостанавливается; обход проверок и CAPTCHA не используется. Изменение разметки или ограничения источника могут повлиять на сбор. Полное покрытие каталога и обнаружение каждого объявления не гарантируются.

Время находки означает момент обнаружения объявления. Сортировка по новизне не служит проверкой даты публикации; дата указана на Vinted. Доставка уведомлений зависит от очереди и доступности Telegram.

Vinted Radar — независимый проект, не связанный с Vinted.
