# Vinted Radar

> **Бюджет: 0 € (обновлено 24 октября).** Не запускайте платный Render Blueprint из старой инструкции. Шаблон переименован в `render.paid.example.yaml`. Для бесплатного размещения выбран следующий путь: Cloudflare Workers + D1 + Cron Triggers и Telegram webhook. Текущий сервер на Express/локальной SQLite ещё не адаптирован к Workers; публичное развёртывание пока не выполнено. Начните с `FREE_HOSTING.md`.

Персональный Telegram-бот + Telegram Mini App + устанавливаемая PWA для iPhone и Mac. Интерфейс на React, сервер на Node.js, база SQLite. Независимый проект, не связан с Vinted.

**Реальные объявления Vinted пока не подключены.** По умолчанию работает демонстрационный источник с вымышленными товарами, без фотографий и ссылок на реальные лоты. Новый набор ID создаётся каждые пять минут. Вход в аккаунт Vinted не считается разрешением на автоматический сбор данных. В проекте нет обхода защиты, прокси, извлечения cookies или скрейпера Vinted.

## Что реализовано

- Вход по личному паролю; автоматический вход из Telegram с проверкой подписи, времени и разрешённого пользователя. Для Telegram Web поддерживается проверка подписанного initData на каждом запросе, если браузер блокирует cookies.
- Создание, изменение, удаление и приостановка поисков: слова, бренд, размер, цена в EUR, интервал 1/5/15/30/60 минут.
- Проверка расписания каждые 15 секунд, ручная проверка с ограничением частоты.
- Сохранение поисков, находок, избранного, сессий, очереди уведомлений и смещения Telegram в SQLite.
- Дедупликация по паре «поиск + ID товара», очередь с повторными попытками после ошибки Telegram.
- Бот: /start, /status, /stop; кнопка открытия приложения и тестовое уведомление.
- Одна база для Telegram и браузера, адаптивный интерфейс, PWA-манифест и экран отсутствия сети.
- Экспорт поисков JSON, резервное копирование SQLite, Docker и Render Blueprint.
- Модульные и HTTP-тесты, включая сохранение данных при перезапуске.

Это **одна личная установка**, не многопользовательский сервис. Владелец Telegram и любой человек с паролем видят общие поиски. Для подруги лучше развернуть отдельную копию с её ботом, паролем и Telegram ID.

## 1. Запуск на Mac — без Telegram

### Установить Node.js

1. Откройте https://nodejs.org/en/download и скачайте установщик **Node.js 24 LTS** для macOS.
2. Откройте скачанный `.pkg`, завершите установку.
3. Откройте Terminal через Spotlight: `⌘ Space` → `Terminal` → Enter.
4. Введите `node -v`. Нужна версия 24 или выше. Затем `npm -v`.

### Открыть проект

Если используете папку, созданную в этом чате:

```bash
cd "$HOME/Documents/vinted-radar"
```

Если скачали ZIP: распакуйте его в Finder, в Terminal напишите `cd ` (с пробелом), перетащите папку `vinted-radar` в окно Terminal и нажмите Enter. Все последующие команды выполняются из этой папки.

### Создать настройки

```bash
cp .env.example .env
openssl rand -hex 24
```

Вторая команда покажет случайный пароль. Сохраните его в менеджере паролей.

Откройте `.env` в редакторе. На Mac можно выполнить:

```bash
nano .env
```

Замените значение `APP_PASSWORD=replace-with-a-long-private-password` на сгенерированный пароль, без пробелов и кавычек. Оставьте `BOT_TOKEN` и `TELEGRAM_OWNER_ID` пустыми. Сохранить в nano: `Control O`, Enter, `Control X`.

```bash
npm ci
npm run build
npm start
```

Откройте **http://localhost:3000** в Safari или Chrome. Введите пароль из `.env`.

Terminal должен оставаться открытым. Остановка: `Control C`. Повторный запуск: `npm start`. При выключении или сне Mac мониторинг локального сервера прекращается.

### Первая проверка

1. Нажмите **Новый поиск**.
2. Название: `Жакеты COS`; ключевые слова: оставьте пустыми; бренд: `COS`; размер: `M`; цена: `45`; интервал: `1 мин.`.
3. Нажмите **Запустить поиск**, затем перейдите в **Находки**.
4. В деморежиме появятся вымышленные жакеты. Добавьте один в избранное.
5. В **Мои поиски** проверьте редактирование, паузу и возобновление.
6. Перезапустите сервер: поиск и избранное сохранятся.
7. Через пять минут появится новый демонабор; до наступления срока следующей проверки он в ленту не попадёт. Можно нажать **Проверить сейчас**.

Первый запуск поиска сохраняет все совпадения, доступные в источнике в этот момент, и при подключённом боте отправляет их. После этого уведомления создаются только для новых ID. При подключении Telegram старые находки задним числом не отправляются.

## 2. Создать Telegram-бота

1. В Telegram найдите **@BotFather** — официальный аккаунт Telegram.
2. Отправьте `/newbot`.
3. Задайте имя, например `Personal Finds Radar`.
4. Задайте свободный username с окончанием `bot`.
5. BotFather выдаст **токен**. Это секрет; вставляйте его только в `.env` или секретные настройки хостинга. Не отправляйте в чат, не публикуйте в GitHub и не добавляйте в React-код.

### Узнать свой Telegram ID без стороннего бота

1. Отправьте своему новому боту `/start`.
2. Пока сервер с этим ботом ещё не запущен, выполните следующую команду в Terminal из проекта. Токен автоматически прочитается из `.env`, команда его не выводит.
3. Сначала заполните `BOT_TOKEN=...` в `.env`, оставляя Telegram ID пустым.

```bash
node --env-file=.env --input-type=module -e 'const r=await fetch(`https://api.telegram.org/bot${process.env.BOT_TOKEN}/getUpdates`);const d=await r.json();if(!d.ok)throw Error(d.description);for(const u of d.result)if(u.message?.chat.type==="private")console.log({telegramId:u.message.from.id});'
```

Если список пуст, отправьте ещё одно сообщение боту и повторите. Если установлен старый webhook, удалите его через настройку из следующего раздела или используйте нового бота. Эта команда и приложение не должны опрашивать одного бота одновременно.

4. В `.env` заполните `TELEGRAM_OWNER_ID=ваш_числовой_ID`.
5. Перезапустите `npm start` и снова отправьте боту `/start`.
6. В приложении откройте **Подключение → Отправить тест**.

Локально уже работают сообщения бота. Mini App требует публичный **HTTPS** адрес, поэтому кнопка приложения появится после размещения. Бот принимает команды только из личного чата указанного владельца. Для отключения уведомлений отправьте `/stop`; для возврата `/start`.

## 3. Разместить сервер и Mini App

Нужен постоянно работающий сервер с постоянным диском. Ниже готовый путь через Render. Он использует **платный** web service и диск; актуальную стоимость посмотрите перед созданием ресурсов. Бесплатный спящий сервер не обеспечивает постоянный мониторинг, а файловая система без диска теряет SQLite при перезапуске/развёртывании. Бесплатно можно проверять локально на Mac, пока он включён и не спит.

### Загрузить код в GitHub

1. Создайте аккаунт на https://github.com, если его ещё нет.
2. Создайте **private** репозиторий `vinted-radar`, не добавляя README на сайте.
3. Удобный путь для новичка: установите GitHub Desktop с https://desktop.github.com.
4. В GitHub Desktop выберите **File → Add Local Repository** и эту папку. Если это не репозиторий, нажмите предложенное **Create a Repository**, указав именно папку проекта.
5. Убедитесь, что среди файлов коммита **нет `.env` и папки `data`**. Они исключены через `.gitignore`.
6. Создайте первый commit и нажмите **Publish repository**, оставив **Keep this code private**.

### Render — пошагово

1. Откройте https://dashboard.render.com и подключите GitHub.
2. Выберите **New → Blueprint**, затем репозиторий `vinted-radar`. Это платный вариант вне текущего бюджета. Только если позже выберете платный Render, переименуйте `render.paid.example.yaml` в `render.yaml` в корне репозитория.
3. Render покажет сервис `vinted-radar`, план и диск. Проверьте стоимость до подтверждения.
4. Заполните запрошенные переменные:
   - `BOT_TOKEN` — токен BotFather.
   - `TELEGRAM_OWNER_ID` — ваш числовой ID.
   - `PUBLIC_URL` — можно временно указать `https://example.com`, затем обязательно заменить на реальный адрес сервиса.
5. Создайте Blueprint и дождитесь статуса **Live**.
6. Скопируйте адрес вида `https://vinted-radar-xxxx.onrender.com` из страницы сервиса.
7. В **Environment** установите `PUBLIC_URL` равным этому адресу **без завершающего слеша**. Сохраните и дождитесь перезапуска.
8. В **Environment** посмотрите сгенерированное `APP_PASSWORD`; это пароль входа в размещённое приложение. Сохраните его. Это не локальный пароль из `.env`.
9. Проверьте наличие диска в **Disks**: путь `/var/data`; `DATABASE_PATH=/var/data/radar.sqlite`. Запускайте **один экземпляр**, без масштабирования: этот вариант использует локальную SQLite и один процесс опроса Telegram.
10. Откройте HTTPS-адрес, войдите, создайте поиск. Размещённая база начинается пустой; локальные данные автоматически не переносятся.
11. Остановите локального бота (`Control C`), прежде чем пользоваться размещённым: два процесса не должны опрашивать один токен.
12. Отправьте `/start` вашему боту и проверьте тестовое уведомление из приложения.

### Включить кнопку Mini App

В локальном `.env` замените `PUBLIC_URL` на HTTPS-адрес Render. Убедитесь, что указан тот же BOT_TOKEN, что на сервере. Не запускайте локальный сервер с этим токеном одновременно с хостингом.

```bash
npm run telegram:setup
```

Эта команда регистрирует команды и кнопку меню, удаляет webhook (проект использует long polling). Затем отправьте боту `/start`: появится кнопка **Открыть Vinted Radar**, а внизу чата — меню приложения. Нажмите кнопку: приложение должно войти без пароля через проверенную подпись Telegram.

Можно также настроить **Main Mini App** в BotFather: `/mybots` → ваш бот → Bot Settings → Configure Mini App (названия пунктов могут меняться) → указать тот же HTTPS-адрес. Для основного сценария достаточно уже настроенной кнопки меню.

### Установить на iPhone / Mac

- iPhone: откройте HTTPS-адрес в **Safari**, войдите → «Поделиться» → «На экран Домой» → «Добавить».
- Mac: Safari → откройте HTTPS-адрес → **Файл → Добавить в Dock** (в поддерживаемых версиях macOS).
- В Chromium-браузере можно использовать значок установки приложения возле адресной строки, если он доступен.

PWA использует тот же сервер. Она не выполняет мониторинг сама в фоне на iPhone. Открытый сайт и Telegram Mini App могут иметь отдельные cookies; в Safari используйте пароль. Офлайн показывается экран отсутствия связи; приватная лента не сохраняется в service-worker cache.

## 4. Подключить разрешённые данные

До получения конкретного разрешения оставьте `DATA_SOURCE=demo`.

Когда есть ваш собственный каталог или источник, условия которого явно разрешают такое использование:

1. Подготовьте JSON-массив по образцу `authorized-feed.example.json`.
2. Используйте стабильный уникальный `id`, цену числом, валюту `EUR`, HTTPS-ссылку (необязательно), строки `title`, `brand`, `size`.
3. Запишите файл `data/authorized-feed.json` локально или `/var/data/authorized-feed.json` на Render через Shell. Файл должен обновляться вашим разрешённым поставщиком; приложение лишь перечитывает его. Для обновлений используйте запись во временный файл и переименование, чтобы не прочитать половину JSON.
4. Настройте:

```dotenv
DATA_SOURCE=authorized-file
AUTHORIZED_FEED_CONFIRMED=true
AUTHORIZED_FEED_PATH=/var/data/authorized-feed.json
```

Локально путь будет `./data/authorized-feed.json`. Перезапустите сервер. Некорректный JSON отображается как ошибка поиска; повторная попытка через минуту. При смене источника старые демонаходки останутся помечены «ДЕМО»: удалите демопоиски и создайте новые, чтобы начать чистую ленту.

Поле `AUTHORIZED_FEED_CONFIRMED` — технический предохранитель, а не получение прав. Разрешение на доступ к Vinted нужно установить отдельно. Готового подключения к реальному Vinted API или скрейпингу в этой версии нет.

## 5. Разработка, тесты и резервные копии

```bash
npm test
npm run build
```

Для разработки откройте два окна Terminal из папки проекта:

```bash
npm run dev
```

Во втором:

```bash
npm run web
```

Откройте http://localhost:5173. Не используйте `COOKIE_SECURE=true` для локального HTTP. В production приложение и API обслуживаются одним сервером, отдельный фронтенд-хостинг не нужен.

Резервная копия без остановки базы:

```bash
node --env-file-if-exists=.env scripts/backup.js
```

Скопируйте созданный файл из `backups/` в надёжное место вне сервера. Он содержит приватные поиски и сессии. На Render путь базы уже задан окружением; выполните `node scripts/backup.js` в Shell и скачайте/выведите копию подходящим защищённым способом. Наличие копии на том же сервере не защищает от его удаления.

Восстановление: остановите сервис, сохраните текущую базу и файлы `-wal`/`-shm` отдельно, замените базу резервной копией, удалите старые файлы `-wal`/`-shm` из рабочей папки, затем запустите сервис. Не копируйте только открытый `.sqlite` файл без SQLite backup: свежие записи могут находиться в WAL.

Смена пароля: замените `APP_PASSWORD`, затем для завершения старых сессий выполните при остановленном сервере:

```bash
node --env-file-if-exists=.env --input-type=module -e 'import {DatabaseSync} from "node:sqlite";const d=new DatabaseSync(process.env.DATABASE_PATH||"./data/radar.sqlite");d.exec("DELETE FROM sessions");d.close();'
```

### Docker (дополнительный вариант)

При установленном Docker Desktop, после заполнения `.env`:

```bash
docker compose up -d --build
```

Откройте http://localhost:3000. Данные находятся в именованном томе `radar-data`. Для размещения на VPS нужны HTTPS reverse proxy, домен, `.env` с `COOKIE_SECURE=true`, `TRUST_PROXY=1`, корректный `PUBLIC_URL` и резервные копии тома. Готовый VPS автоматически не создаётся.

## Ограничения и эксплуатация

- Только один владелец и один экземпляр сервера; пароль предоставляет полный доступ ко всем данным.
- Фильтры ищут все слова в названии/бренде, бренд и размер совпадают точно без учёта регистра. Валюта только EUR; перевода запросов, категорий и конвертации валют нет.
- Изменение фильтров сохраняет старые находки. Удаление поиска удаляет его находки, избранное и очередь сообщений.
- Пауза останавливает новые проверки, но уже созданная очередь уведомлений может быть доставлена. `/stop` отключает Telegram и очищает ожидающую очередь.
- Telegram может редко повторить сообщение, если оно принято Telegram, а сервер аварийно остановился до записи результата в SQLite. Доставка «ровно один раз» через внешний API не гарантируется.
- При блокировке бота пользователем очередь сохраняется и повторяет попытки с задержкой до часа; статус ошибки виден в «Подключение».
- Сервер хранит историю без автоматической очистки, а интерфейс показывает последние 500 совпадений. Контролируйте диск, особенно при длительном деморежиме.
- SQLite встроена в Node; в некоторых версиях Node 24 выдаёт предупреждение об экспериментальном API. Это не ошибка запуска.
- Развёртывание в вашем аккаунте, проверка настоящего Telegram-чата и установка на физический iPhone требуют ваших действий и пока не подтверждены автором проекта.

## Если что-то не работает

| Симптом | Что сделать |
|---|---|
| `node: command not found` | Установить Node 24, закрыть и снова открыть Terminal |
| APP_PASSWORD error | Создать `.env`, указать уникальный пароль не короче 16 символов |
| Пустая лента | Создать активный поиск, попробовать COS / M / до 45 €, нажать проверку |
| Telegram не отвечает | Проверить BOT_TOKEN и числовой ID, отправить /start; остановить второй процесс бота |
| Telegram conflict / webhook | Выполнить telegram:setup с HTTPS PUBLIC_URL и оставить один процесс |
| Вход после размещения не работает | PUBLIC_URL точно совпадает с адресом в браузере без завершающего `/`, COOKIE_SECURE=true и HTTPS |
| Данные исчезли после deploy | Проверить постоянный диск и DATABASE_PATH внутри него |
| Mini App не входит автоматически | Открыть через web_app-кнопку бота, проверить TELEGRAM_OWNER_ID, закрыть/открыть для свежего initData |
| Новые вещи не приходят | Проверить паузу, время следующей проверки и ошибки источника/Telegram в приложении |
